# Game sound effects

The sound files in this folder were selected from the following Kenney asset packs:

- Interface Sounds (1.0): https://kenney.nl/assets/interface-sounds
- Impact Sounds (1.0): https://kenney.nl/assets/impact-sounds
- Digital Audio: https://kenney.nl/assets/digital-audio

Each source pack is licensed Creative Commons Zero (CC0):
https://creativecommons.org/publicdomain/zero/1.0/

The included Kenney license files state that the assets may be used in personal,
educational, and commercial projects and that attribution is not required.

Files here were renamed for their Ms. Sonoma game event. The original packs were
downloaded on 2026-09-25 and audited before this subset was selected.

Audio is intentionally low-volume in code and each game has its own sound palette
so repeated play does not make every game sound identical.
